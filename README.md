# astrbot_plugin_wuxianews

天涯明月刀公告插件（AstrBot）：天刀公告列表、天刀最新公告（手机网页整页截图）、定时自动推送。

作者：lianzy

> 更新日志见 [Releases](https://github.com/Lianzy-Baimiao/astrbot_plugin_wuxianews/releases)。

## 指令（裸词即可触发，/ 前缀可省略）

所有指令统一以 `天刀` 开头，避免与其它插件的裸词指令冲突。

| 指令 | 说明 |
|---|---|
| `天刀公告列表` | 最近 10 条天刀公告（类型/标题/时间/链接） |
| `天刀最新公告` | 最新一条公告：文字（类型/标题/日期/链接/摘要）+ 手机网页整页截图 |
| `天刀最新公告改` | 有新公告才返回（按群去重） |
| `天刀新闻推送 开/关/状态/测试` | 本群开启后**每 5 分钟检查**，有更新自动推送（开/关/测试需管理员） |
| `天刀重置公告推送` | 清空本群推送记录（需管理员） |

## 配置（WebUI 插件配置页）

| 配置项 | 默认 | 说明 |
|---|---|---|
| `news_groups` | `[]` | 定时推送的群（填**群号**或 unified_msg_origin，可多个）。也可以在群里发 `天刀新闻推送 开` 自动登记本群，**或直接在插件面板里按群名勾选** |
| `shot_enabled` | `true` | 公告图用手机网页整页截图；关掉则回到深色卡片图 |
| `shot_max_height` | `5000` | 截图最大高度（CSS 像素，0 = 不截断）。超长公告截取前面部分，文字消息里提示看链接 |
| `shot_quality` | `88` | 截图 JPEG 质量。成图超过 2.5MB 会自动继续降质/缩放 |

## Web 面板（推荐用来管推送群）

AstrBot WebUI → 插件 → 天刀公告 → 打开面板（需要 AstrBot ≥ 4.24.1）：

- **推送群**：按**群名**勾选要推送的群（下拉/弹窗里都是「群名（群号）」），不用记群号；`选择群…` 里可以搜索群名或群号，还能「刷新群列表」把机器人所在的全部群一次拉出来
- **立刻检查并推送**：不用等 5 分钟轮询周期，手动跑一轮（单群「测试推送」还能强制重发，用来验证群里到底收不收得到）
- **推送记录**：每个群上次推的公告标题，支持单群/全部重置
- **截图画廊**：公告截图缓存缩略图 + 占用空间，一键清空；截图参数（开关/最大高度/质量）也能在面板里改
- `选择群…` 的勾选结果要点「保存推送群」才写回配置（与群里 `/天刀新闻推送 开` 改的是同一份 `news_groups`）

> 群名单里填**裸群号**时，插件会把它补成「平台**实例 id** + GroupMessage + 群号」（例如
> `napcat:GroupMessage:123`）。要填实例 id 而不是适配器类型名：AstrBot 的 `send_message` 按实例 id
> 匹配平台，写 `aiocqhttp:GroupMessage:123` 这种发不出去。

群名从哪来：群里来消息时顺手记（平台事件自带群名就直接用），首次见到某个群会后台问一次
`get_group_info`，点「刷新群列表」则调 `get_group_list` 一次补齐所有群 —— 所以**群里没说过话的群
也能按群名选到**。名字缓存落在 `groups.json`，查不到名字就显示「群 群号」，不影响推送。

## 数据存储

- 推送去重记录：`data/plugin_data/astrbot_plugin_wuxianews/push_record.json`
- 摘要缓存（24h）：同目录 `summary_cache.json`
- 网页截图缓存：同目录 `news_shots/`（按 URL 哈希命名，保留最近 20 张 + 7 天兜底）
- 群名缓存（面板显示用）：同目录 `groups.json`（可删，删了只是面板里重新显示群号）

## 说明

- 公告数据源：`wuxia.qq.com`（GBK 编码，自动转码解析）
- **公告图**：Playwright 以 iPhone UA + 390×844 手机视口打开公告网址整页截图，版式与手机访问官网一致。浏览器组件首次使用时自动后台下载（约 150MB），下载期间/失败时回退为 `templates/news.html` 渲染的深色卡片图
- 截图时**关闭 JavaScript**：天刀公告页 head 里有 `window.location.href` 整页跳转脚本，开着 JS 会被劫持到活动页；正文配图是普通 `<img src>`，关 JS 不影响加载
- 少数「跳转型公告」（正文为空，手机上点进去直接跳活动页）会自动识别并改截那个活动页，并遮掉腾讯游戏活动页的扫码登录弹窗
- 管理指令（开/关/测试/重置）需要 AstrBot 的 `admins_id`（WebUI 配置，非 QQ 群管理）
